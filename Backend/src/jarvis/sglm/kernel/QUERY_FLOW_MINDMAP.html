📋 Pipeline Registry: Where, Why, and How

Step Where (File & Method) Why (Architectural Reason) How (Computation & Result)
1. Ingestion SGLMBrain.js
query()		 Autonomous memory access without external hardcoded routing. Extracts clean S-R-O triples from MongoDB records.
2. Tokenization TransparentInspectableTokenizer.js
encode()		 Dynamic vocabulary discovery; avoids subword fragmentation of entities. Boundary normalization + dynamic registry lookup; prepends <|bos|>.
3. Embed & RoPE MultiHeadCopyTransformer.js
wte + _applyRoPE()		 Maps discrete IDs into continuous space while preserving relative distances. x0 = wte * sqrt(dModel); applies 2D rotary rotation pairs to $(Q, K)$.
4. Blocks (0 & 1) MultiHeadCopyTransformer.js
_forwardBlock()		 Constructs deep relational representations between subject and relation slots. Pre-RMSNorm → Multi-Head Self-Attention → Residual → FFN → Residual.
5. Content Salience MultiHeadCopyTransformer.js
querySpan IPR		 Suppresses syntax noise ("Who", "?") without hardcoding word blacklists. Continuous Inverse Participation Ratio: IPR = sum(p_j^2) isolates salient words.
6. Copy Head MultiHeadCopyTransformer.js
Copy Attention Loop		 Head factorization: Head 0 locks on Subject, Head 1 locks on Relation. score = (CQ * CK) / sqrt(dH) → Mask BOS/Self/Question → Softmax average.
7. Decision SGLMBrain.js & OutputHead
Candidate Argmax		 Converts continuous attention back to symbolic entity tokens. P(tok) = sum(copyWeights) → selects top token (latency <5ms, 0 API tokens).
